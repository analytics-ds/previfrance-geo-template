# Maquettes GEO Prévifrance (datashake)

Deux pages de previfrance.fr reproduites à l'identique, avec les ajouts GEO en pastilles rouges cliquables :

- `conseils-mutuelle-senior.html` : page conseil « Les conseils pour choisir une mutuelle senior », 8 pastilles.
- `mutuelle-sante-senior.html` : page d'offre « Mutuelle santé senior et retraité », 8 pastilles.

Maquettes de démonstration, non affiliées à la Mutuelle Prévifrance, en `noindex`. Les textes d'origine sont conservés, les valeurs des niveaux intermédiaires du tableau de garanties sont indicatives.
